Purpose

This is the main BUILDING department.

It contains substantial standalone projects that turn knowledge into working systems, products, experiments or demonstrations.

Project rule

The category structure is standardized.

Individual projects are flexible.

A project may contain:

README.md
documentation/
hardware/
firmware/
software/
simulation/
experiments/
data/
results/
media/

Only create folders that the actual project needs.

Project lifecycle

IDEA
→ DEFINE
→ PLAN
→ BUILD
→ TEST
→ DOCUMENT
→ RELEASE
→ REVIEW
→ ARCHIVE

Projects should leave behind reusable knowledge and portfolio evidence.
